## Structure

Each poster lives in its own folder (`YYYY-event-topic/`) with:

- `index.html` – mobile-friendly page (the QR code on the printed poster points here)
- `poster.pdf` – full-resolution poster
- `preview.jpg`, `thumbnail.jpg` – images for the web page
- `qr.svg`, `qr.png` – QR code pointing to the poster page

Folder names are permanent: the printed QR codes depend on them. To update a poster, replace its `poster.pdf` (and previews) and keep the folder name.
